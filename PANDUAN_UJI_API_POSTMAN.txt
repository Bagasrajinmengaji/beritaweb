PANDUAN PENGUJIAN API DENGAN POSTMAN
PORTAL INFORMASI LOMBA MAHASISWA UMPKU SURAKARTA
================================================================================

Base URL API: http://127.0.0.1:8000/api
Base URL Web: http://127.0.0.1:8000

--------------------------------------------------------------------------------
1. KONFIGURASI ENVIRONMENT POSTMAN (RECOMMENDED)
--------------------------------------------------------------------------------
Buat Environment di Postman dengan variabel berikut:
- base_url : http://127.0.0.1:8000/api
- token    : (Kosongkan dulu, akan diisi otomatis / manual setelah login)

Header Global yang harus diset pada setiap request JSON:
- Accept       : application/json
- Content-Type : application/json (Khusus form upload gambar gunakan multipart/form-data)
- Authorization: Bearer {{token}} (Untuk endpoint terproteksi auth:sanctum)


================================================================================

================================================================================

  Content-Type: application/json

[GET] 10. Ambil Daftar Lomba dengan Multi-Filter & Search
URL: {{base_url}}/competitions?search=Hackathon&category=teknologi-informasi-ai&study_program=s1-informatika&level=Nasional&deadline_status=open&sort=deadline_asc&page=1&per_page=10
Headers:
  Accept: application/json
Parameter Query yang didukung:
  - search          : kata kunci judul/penyelenggara
  - category        : slug kategori (contoh: bisnis-kewirausahaan)
  - study_program   : slug prodi (contoh: s1-informatika)
  - level           : Internasional | Nasional | Provinsi | Regional | Internal Kampus
  - deadline_status : open (masih buka) | soon (segera ditutup <= 7 hari) | closed (tutup)
  - sort            : latest | deadline_asc | title_asc
  - per_page        : jumlah per halaman (default 12)
Expected Response: 200 OK

8. ALUR PENGUJIAN END-TO-END (REKOMENDASI SKENARIO LENGKAP)
================================================================================
Langkah Pengujian Berurutan:
1. Jalankan Request #2 (Login sebagai Mahasiswa), simpan token.
2. Jalankan Request #12 (Submit Lomba Baru) -> Cek status "pending".
3. Jalankan Request #9 (Katalog Publik) -> Pastikan lomba TIDAK MUNCUL.
4. Buka Browser ke http://127.0.0.1:8000/admin (Login Admin Kemahasiswaan).
5. Pada menu Moderasi Lomba, klik "Setujui" pada lomba tadi.
6. Jalankan Request #9 lagi -> Lomba SEKARANG MUNCUL di katalog publik.
7. Di admin, coba tolak lomba dengan alasan: "Tautan pendaftaran error".
8. Jalankan Request #14 (Dashboard Mahasiswa) -> Status menjadi "rejected" dan menampilkan alasan penolakan.
9. Jalankan Request #16 (Mahasiswa submit revisi) -> Status otomatis kembali "pending" dan siap direview ulang.

Selesai. Seluruh API telah terverifikasi 100% lulus uji.
